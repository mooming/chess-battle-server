Chess Battle Server – Protocol Overview

This document shows the binary protocol used by the server and a complete short game (Scholar’s Mate) illustrated with SVG board diagrams.

1. Protocol Message Examples

All messages start with a 16‑bit Protocol ID (PID) followed by a length field (when the payload is variable) and then the payload bytes. Below is a visual flow of a client connecting, performing the handshake, and then sending moves.

Handshake (Human readable):
Client → Server Greeting:
  PID: 0x0001 (Greeting)
  Version: 0x0001
  Name: "ChessClient"

Server → Client Greeting:
  PID: 0x0001 (Greeting)
  Version: 0x0001
  Name: "ChessServer"

Server → Client ConnectionSucceeded:
  PID: 0x0002 (ConnectionSucceeded)
  Message: "Welcome"

Client → Server ConnectionSucceeded:
  PID: 0x0002 (ConnectionSucceeded)
  Message: "Welcome"

Key PIDs used in this example:

  • 0x0001 – Greeting (version, name)
  • 0x0002 – ConnectionSucceeded
  • 0x0003 – ConnectionFailed
  • 0x0200 – Move (pawn/figure movement)
  • 0x0300 – VerifyGameState
  • 0x0401 – GameState (FEN string)

2. Full Game Example – Scholar’s Mate

The following PGN shows a classic four‑move checkmate. Each move is represented as a Move protocol message (PID 0x0200) with the 4‑character square codes (e.g., e2e4).

1. e2e4   // White pawn from e2 to e4
1... e7e5 // Black pawn from e7 to e5
2. d1h5   // White queen from d1 to h5 (threatening f7)
2... b8c6 // Black knight from b8 to c6 (defensive move)
3. f1c4   // White bishop from f1 to c4 (targets f7)
3... g8f6 // Black knight from g8 to f6 (blocks queen)
4. h5f7#  // White queen captures on f7 delivering checkmate

3. Protocol Message Payload for the Game

Each move is sent as a Move message (PID 0x0200) with a 4‑character square code (origin + destination). Example binary payloads (hex):

  • 1.e2e4 → 02 00 65 32 65 34 (PID 0x0200, ASCII "e2e4")
  • 1...e7e5 → 02 00 65 37 65 35
  • 2.Qh5 → 02 00 68 35 68 35 (queen moves from d1 to h5, encoded as "h5h5" for illustration)
  • … and so on, ending with 02 00 66 37 66 37 for the final queen capture on f7.

After the final move the server replies with a GameState (PID 0x0401) containing the final FEN string, confirming checkmate.

All protocol definitions and the example game are intended for developers integrating a chess AI or UI with the Chess Battle Server.
